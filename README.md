# Помогатор 1С

Помощник для работы с 1С. Вы спрашиваете о данных своей базы обычными словами, а Помогатор отвечает цифрами и таблицей прямо в окне 1С: кто из покупателей должен больше всех, какие остатки на складе, какими документами сформированы обороты по счёту.

![Первый экран сайта Помогатора 1С](landing.png)

## Как это работает

Помогатор подключается к базе через внешнюю обработку 1С. Её открывают в своей базе, в обработке открывается чат, и можно задавать вопросы.

- Обработка только читает данные. Создавать, проводить или удалять документы она не умеет.
- Ставить программы на сервер 1С и открывать порты не нужно.
- Под ответом написано, из каких данных и за какой период он посчитан.
- Если вопрос сложный, в том же чате отвечает специалист 1С.
- Историю вопросов и расход видно в личном кабинете.
